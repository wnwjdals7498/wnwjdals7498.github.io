# wnwjdals7498.github.io

> 상태: 계획 단계. 사이트 구현·배포·검증 전.

이 폴더는 공개 포트폴리오 사이트를 위한 작업 공간이다. 프로젝트 구현 전에 사이트를 개설하고, 각 프로젝트의 계획·진행·구현·검증 상태를 실제 결과에 맞춰 표시한다.

## 공개할 내용

- 프로젝트별 배경, 개인 역할, 구현 내용, 검증 결과와 공개 코드 링크
- 회사에서 수행한 업무와 개인 환경에서 재현한 구현의 구분
- 기록과 대조한 재직 기간·직무·팀 변경 시점

회사·서비스·제품명은 익명화한다. 연락처는 [GitHub 프로필](https://github.com/wnwjdals7498)만 공개한다. 주간보고와 비공개 자료의 원문은 게시하지 않는다.

현재는 문서와 [UI 가이드](docs/ui/guide.md), [HTML 목업](docs/ui/mockup.html)을 준비했다. 목업은 디자인 검토용이며 사이트 구현·배포·검증은 아직 하지 않았다. 사이트와 프로젝트 결과가 생기면 이 README와 [구축 계획](docs/plan.md)을 갱신한다.
