# wnwjdals7498.github.io

> 상태: GitHub Pages 게시 및 첫 화면·상세 페이지·상태 필터·모바일·404 확인 완료. 소개한 프로젝트 자체는 계획 단계.

시스템 개발·플랫폼 운영 경험을 바탕으로 준비 중인 개인 프로젝트를 소개하는 포트폴리오다. 계획, 진행, 구현, 검증 상태를 구분하고 회사 업무와 개인 환경의 재현 작업을 분리해 설명한다.
