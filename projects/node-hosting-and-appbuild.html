Background & Role

배경과 맡을 일

두 기술 스택에서 같은 VM 관리 요구사항을 구현해 API 응답, 권한, 청구와 실패 처리를 같은 시나리오로 비교합니다.

개인 역할: PHP 구현에서 확정된 계약과 테스트 데이터를 바탕으로 Node 포털을 설계·구현하고 차이를 검증할 계획입니다.

계획한 범위
