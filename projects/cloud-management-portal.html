Background & Role

배경과 맡을 일

클라우드 자원 신청부터 실제 VM 작업, 사용 기간에 따른 청구까지의 흐름을 개인 환경에서 재현할 계획입니다. Linux 고가용성·네트워크 실습도 같은 프로젝트의 범위로 정했습니다.

개인 역할: 요구사항·권한·API 계약을 설계하고 포털, 작업 추적, 인프라 실습과 검증 기록을 직접 구축할 계획입니다.

Planned Scope

계획한 범위

  • 회원·관리자 역할과 VM 신청·조회·조작
  • 신청 직후 Hyper-V VM 생성 작업 시작 및 상태 추적
  • 실제 사양·사용 기간과 사양 변경 이력을 반영한 가상 청구
  • Rocky Linux의 MariaDB Galera, Nginx·Keepalived, VPC 구축 및 제어
First Steps

첫 실행 단계

  1. 실행 환경과 공식 지원 버전 확인
  2. VM 요청·작업 상태·청구 데이터 계약 정의
  3. 테스트 VM 한 대를 만드는 첫 흐름 구현
Verification Plan

검증할 내용

  • 회원은 본인 VM만 조작하고 관리자는 전체 VM을 관리하는지 확인
  • 포털 작업 상태가 실제 Hyper-V VM 상태와 일치하는지 확인
  • Galera 노드 장애·재합류, 접근 경로, VPC 네트워크 동작 검증
출처와 실습 범위

회사에서 경험한 관리포털 업무를 개인 환경에서 새로 재현하는 프로젝트입니다. 회사 원본 코드·화면·데이터는 사용하지 않습니다.

현재는 계획 단계입니다. VM 생성·청구·장애 시험을 실행하지 않았습니다. 모든 VM이 한 물리 호스트에 있다면 물리 호스트 장애 내성을 입증한 것으로 표현하지 않습니다.

공개할 검증 결과는 아직 없습니다.

실제 구현과 시험을 마친 뒤 환경·방법·결과·한계를 기록합니다.
