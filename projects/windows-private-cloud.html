Background & Role

배경과 맡을 일

VM을 수동으로 만들며 구성 요소를 확인한 뒤, 같은 동작을 자동화하고 포털 요청과 실제 VM 결과를 연결합니다.

개인 역할: 호스트 조건을 점검하고 수동·자동화 절차와 실패·복구 사례를 기록할 계획입니다.

Planned Scope

계획한 범위

  • 호스트 CPU·메모리·저장공간·가상화·네트워크 점검
  • Hyper-V Manager에서 VM 한 대 수동 생성
  • PowerShell로 VM 생성·조회·상태 변경·삭제 재현
  • 관리포털 요청 ID·작업 상태·실제 Hyper-V 결과 연결
First Steps

첫 실행 단계

  1. 호스트 자원과 Hyper-V 상태 확인
  2. 테스트 VM 한 대 수동 생성
  3. 동일 작업의 PowerShell 자동화 설계
Verification Plan

검증할 내용

  • 수동 작업과 PowerShell 결과가 일치하는지 확인
  • 반복 실행·실패·재시도·복구 결과 기록
  • 포털 작업 결과와 실제 Hyper-V 상태 비교
출처와 실습 범위

공개 가능한 개인 실습 절차와 결과를 새로 기록합니다. 회사 환경의 구성이나 운영 자료를 복사하지 않습니다.
